# Archived: Chromoku

This folder is the archived copy of the game that was developed here under the working title **Chromoku**
(Aug to Oct 2026, last version v0.20.4). It is kept for history only.

The game was renamed **Quiltoku** and now lives in the private repo `Ronacul/Quiltoku`. Do not develop here.
The reasons for the rename are recorded in `docs/BRAND-MANIFEST.md` in that repo.

- `app/`: the game as it stood at v0.20.4 (`index.html.archived`, service worker, manifest, icons, docs)
- `game.html.archived`: an earlier single-file prototype
- `CHROMOKU*.md`: the original design, plan and backlog documents

The two HTML files carry an `.archived` suffix on purpose, so this repo's GitHub Pages site does not serve them
as a playable page. Rename one back to `.html` to open it locally.
